# 📊 AdTech Break-Even ACoS Calculator

## 📌 Overview
This project calculates Break-Even ACoS to determine whether advertising campaigns are profitable or not.

## 🚀 Features
- Calculate Profit Margin
- Calculate Break-Even ACoS
- Check Profit / Loss status

## 🧠 Use Case
Used in performance marketing platforms like Amazon Ads & Google Ads to:
- Control ad spend
- Improve profitability
- Optimize campaigns

## 💻 Tech Stack
- Python

## 📊 Example
Selling Price: 1000  
Cost Price: 700  
Break-Even ACoS: 30%  
Current ACoS: 25% → Profit
